# Автоматизация разметки данных с помощью моделей

Семинар на 90 минут: человеческая разметка, локальная LLM, сборка промпта, few-shot, размышления, формат ответа, уверенность, гибридные схемы и ансамбль.

[Открыть прогнанный семинар в Colab](https://colab.research.google.com/github/MilordEv/seminar4-automated-labeling-2026/blob/main/seminar.ipynb)

## Запуск

1. Откройте `seminar.ipynb` в Colab и включите GPU.
2. При необходимости раскомментируйте установку зависимостей.
3. Выполняйте ячейки по порядку. Данные скачиваются из **этого** репозитория.

`RUN_LIVE_HF = False` читает сохранённые результаты массовых экспериментов. Одиночные учебные вызовы модели выполняются независимо от флага и требуют загруженной модели. `RUN_SAVE_PREDICTIONS` управляет сохранением результатов. Код служебных ячеек свёрнут, но доступен по кнопке «Показать код».

## Что находится в репозитории

- `seminar.ipynb` — актуальная копия Colab с сохранёнными выводами и графиками.
- `data/` — неподелённая таблица, инструкция людям и используемые иллюстрации.
- `artifacts/` — таблица со сплитами, манифест, обезличенные ответы исполнителей, предсказания модели и ансамбля, итоговая таблица.
- `artifacts/hf_cache/` — шесть совместимых кэшей массовых экспериментов. Неиспользуемые старые кэши не включены.

Всего 260 постов: 60 в банке демонстраций, 50 на calibration, 150 на test. Для few-shot сравниваются 0, 1, 3, 5, 10 и 20 примеров. Промпт и порог выбираются только на calibration; test не используется для подбора.

## Результаты и стоимость

Сохранены ответы существующего прогона, без повторной генерации при публикации. Аналитические метрики, порог и стоимость повторно проверены по сохранённым предсказаниям. Счётчики дополнительных проходов уверенности взяты из сохранённого вывода Colab.

Все цены — **учебные условные единицы**, не денежный прайс. Входные и выходные токены учитываются отдельно; ансамбль оплачивает все модели; гибрид — также расчёт уверенности и назначения людям. Одно человеческое назначение стоит 0,002 у.е.; на сохранённом test это примерно в 5,3 раза дороже основного модельного ответа. Цена применения на test отделена от стоимости поиска промпта.

Схема с увеличением числа людей до пяти — только иллюстрация стоимости: дополнительных человеческих ответов нет, качество в ней является прокси. Она исключена из графика сравнения маршрутизации.

## Данные и приватность

Источник текстов — [RuSentiment](https://github.com/strawberrypie/rusentiment), см. [data/SOURCE.md](data/SOURCE.md). В выводах семинара применяется маскирование нецензурных слов. Исходная подвыборка сохраняется без изменения текста. Исполнители представлены псевдонимами; исходные ID назначений, время отправки и другие ненужные поля не публикуются.

В репозитории нет весов моделей, ключей API, `.env`, ZIP-копий данных, служебных журналов Яндекс Заданий и неиспользуемых старых артефактов.
